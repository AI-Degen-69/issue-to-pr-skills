# CLAUDE.md

This repo is a skill pack. Skills live in `skills/*/SKILL.md`, reviewer personas in `agents/*.md`.

- Use `pipeline-triage` at session start when intent is unclear or the repo is dirty.
- Never invent a missing skill or agent — skip and record.
- Every station ends with evidence (tests, build, runtime), never "seems right".
- Validate with `npm run validate` before pushing.
