# Security Policy

## Reporting a Vulnerability

Open a private security advisory on GitHub or email the maintainer via GitHub profile. Do not open a public issue for sensitive reports.

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ |

We scan dependencies and secrets before every release. The `security-and-hardening` skill and `security-reviewer` agent run on PRs touching auth, input, or data storage.
