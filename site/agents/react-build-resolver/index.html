01 · What it is

Rapid React and modern frontend bundler triage

The react-build-resolver solves the nuanced failures of modern React stacks. From missing "use client" directives in Next.js App Router to mismatched React major versions, JSX transforms, and CSS-in-JS hydration divergence, it repairs the build quickly without touching business logic.

Read & Edit
Context & Patching

Inspects component trees, imports, tsconfig options, and applies precise syntax edits.

Bash
Bundler Execution

Executes npm run build, vite build, next build, and npm ls react.

Grep
Directive & Import Scan

Finds server-only imports leaking into client bundles or hooks called in Server Components.

Glob
Config Discovery

Locates bundler configs (vite.config.ts, next.config.js) and tsconfigs.

Glossary for non-coders: Hydration Mismatch: When HTML rendered on the server differs from what the browser creates on first load. · "use client": A boundary marker telling modern React that this component uses state or browser APIs. · Duplicate React: When two versions of React exist in node_modules, breaking internal hook storage.

03 · Repair playbook

Primary React failure modes and surgical solutions

Sourced directly from agents/react-build-resolver.md, each pattern resolves the cause without modifying logic flow.

Next.js & RSC Boundaries
  • → useState in Server Component: Prepend "use client" to the file's first line or move hook to client child.
  • → Can't resolve 'fs' on client: Move Node-only operations to Server Components or API route handlers.
  • → Hydration mismatch: Move non-deterministic values (Date.now(), localStorage) to useEffect.
JSX, Types & Bundlers
  • → 'React' is not defined: Set "jsx": "react-jsx" in tsconfig for React 17+ transform.
  • → Invalid hook call: Check duplicate React packages via npm ls react and dedupe.
  • → Missing React types: Install matching major @types/react @types/react-dom.

05 · Strict boundaries

What react-build-resolver does NOT do

No disabling type checks

Never silences errors with unprincipled @ts-ignore or disabling strict compiler flags.

No component redesigns

Does not rewrite component hierarchies or styling libraries; fixes the error in the current design.

No unrequested major upgrades

Aligns packages within current major versions rather than forcing major breaking upgrades.
