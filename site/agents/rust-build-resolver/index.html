01 · What it is

Precision borrow checker and compiler diagnostic agent

The rust-build-resolver solves complex Rust ownership, lifetime, and trait implementation errors. It understands the strict requirements of rustc, restructuring borrow scopes, moving ownership cleanly, or adjusting Cargo dependencies without suppressing warnings or compromising safety.

Glossary for non-coders: Borrow Checker: The Rust compiler component ensuring memory safety by verifying that references do not outlive the data they point to. · Lifetimes: Explicit annotations telling the compiler how long different pieces of memory remain valid. · Trait Bounds: Requirements specifying that generic types must support particular behaviors.

03 · Repair playbook

Primary Rust failure modes and surgical solutions

Sourced directly from agents/rust-build-resolver.md, each pattern resolves the cause without modifying logic flow.

Borrow Checker & Lifetimes
  • → cannot borrow as mutable: End immutable borrow before mutable borrow begins, or clone prior to insertion.
  • → does not live long enough: Return owned String instead of reference to dropped local value.
  • → cannot move out of index: Use swap_remove, clone, or restructure to take ownership.
Traits, Types & Cargo.toml
  • → trait not implemented: Add #[derive(...)] or implement trait methods manually.
  • → async fn is not Send: Restructure code so non-Send types are dropped prior to .await calls.
  • → duplicate dependencies: Run cargo tree -d and run cargo update -p <crate> to harmonize versions.

05 · Strict boundaries

What rust-build-resolver does NOT do

No unsafe shortcuts

Never introduces unsafe blocks to work around borrow checker or lifetime constraints.

No unwrap() patching

Never adds panicking .unwrap() to silence type errors; propagates errors cleanly using ?.

No #[allow(unused)]

Fixes dead code and unused imports directly rather than silencing the compiler with suppression attributes.
