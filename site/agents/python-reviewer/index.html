01 — What it is

Static audit and Pythonic idiomatic guard

The python-reviewer establishes scope with git diff -- '*.py', coordinates static linters, and checks for subtle language traps like mutable default arguments, bare except blocks, and un-awaited coroutines.

Read
Module Context

Reads the surrounding module hierarchy, type declarations, imports, and docstrings.

Grep
Anti-pattern Scanner

Detects bare except:, def f(x=[]) mutable defaults, and unparameterized SQL f-strings.

Glob
Package Discovery

Locates pyproject.toml, setup.cfg, requirements.txt, and framework settings modules.

Bash
Linter Suite

Executes non-destructive checks: ruff, mypy, black --check, and bandit.

Glossary for non-coders: PEP 8: the official style guide for Python code readability and formatting. · Mutable Default: setting a default parameter to [] or {}, which shares state across all function calls and causes silent bugs. · Bare Except: catching all errors without specifying an exception class, which accidentally swallows keyboard interrupts and system exits.

03 — Review checklist

Core review priorities & framework hygiene

Sourced directly from agents/python-reviewer.md:27-100, ensuring type safety, security, and clean architecture.

CRITICAL — Security & Bare Excepts

Flaws that breach security or completely swallow errors.

  • ✕ SQL injection via f-strings: f"SELECT * FROM users WHERE id = {user_id}" instead of query parameters.
  • ✕ Command injection: Passing untrusted strings to os.system or subprocess(shell=True).
  • ✕ Bare except: Using except: pass which silently traps KeyboardInterrupt and memory errors.
  • ✕ Unsafe deserialization: Loading untrusted payloads with pickle.loads or yaml.load without SafeLoader.
HIGH — Types, Idioms & Concurrency

Violations of Pythonic design that degrade maintainability or cause race conditions.

  • ✕ Mutable default arguments: def add_item(item, items=[]) — use items=None.
  • ✕ Missing type hints: Public exported functions lacking type annotations or using Any lazily.
  • ✕ Mixing sync and async: Calling blocking synchronous I/O inside async functions without thread offloading.
  • ✕ Missing context managers: Opening files or network sockets without with blocks.
MEDIUM — PEP 8 & Code Style

Standard library conventions and clean code hygiene.

  • ✕ Wildcard imports: from module import * which pollutes the module namespace.
  • ✕ Print statements in production: Using print() instead of standard logging.
  • ✕ None comparison: Writing val == None instead of identity check val is None.
Framework Specifics

Dedicated checks for Django, FastAPI, and Flask.

  • ✓ FastAPI: Validates Pydantic response models and ensures non-blocking async endpoint handlers.
  • ✓ Django: Enforces select_related / prefetch_related to prevent N+1 query cascades.
  • ✓ Flask: Verifies CSRF protection and centralized error handling middleware.
04 — When it runs

Concrete real-world scenarios

1. Adding a FastAPI route

When adding an endpoint handling request bodies, the reviewer ensures Pydantic models validate input, type annotations are explicit, and CORS settings are restricted.

2. Async database querying

Flags accidental synchronous ORM calls inside an async def coroutine that would block Python's event loop for all concurrent requests.

3. Django model relationship query

Identifies loops iterating over foreign keys without select_related, replacing an N+1 query explosion with a single batch fetch.

05 — Output format & verdict

Standardized output finding

[CRITICAL] SQL Injection via formatted string
File: app/routers/users.py:45
Issue: User input `username` is directly interpolated into raw SQL query via f-string.
Fix: Replace f-string with parameterized query tuple to prevent SQL escape.
# BAD: User input interpolated into SQL query string
cursor.execute(f"SELECT * FROM users WHERE username = '{username}'")

# GOOD: Parameterized query safely handled by DB driver
cursor.execute("SELECT * FROM users WHERE username = %s", (username,))

06 — Strict boundaries

What python-reviewer does NOT do

Does not rewrite code

The agent provides precise diagnosis and remediation code snippets, but never writes files or auto-applies commits.

No imaginary commands

Triggered via pipeline Station IV (iv-review-build-and-pr). There are no ad-hoc slash commands like /python-review in this repository.

Skipped if missing

If a persona file is not present on disk, Station IV logs its absence and skips it cleanly rather than simulating fake output.
