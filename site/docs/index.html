3 ways in — pick one

Any agent — easiest
npx skills add AI-Degen-69/issue-to-pr-skills
Works with Claude, Cursor, Copilot, OpenCode and 70 more. Try --list to browse first.
Claude Code — plugin
/plugin marketplace add AI-Degen-69/issue-to-pr-skills/plugin install issue-to-pr-skills@ai-degen-marketplace
Auto-updates.
Manual
copy skills/ → .agents/skills/
Copy folders yourself. See getting-started guide.
What you need
git + gh (GitHub CLI). CodeRabbit is optional — without it, the AI does the review.
First run — 1-2-3
1. Open a repo with issues → 2. Type /i-pick-issue → 3. Pick an issue and follow the stations.
How to know it worked
Each station ends with a short report: what was done, proof it works, and the single next step. Run npm run validate to check locally.
