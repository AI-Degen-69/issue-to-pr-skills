# Testing Patterns

- **TDD:** red → green → refactor, one vertical slice per commit (Station III).
- **Pyramid:** 80% unit, 15% integration, 5% E2E.
- **Browser:** use `browser-testing-with-devtools` for live runtime proof (DOM, console, network).
- **Anti-patterns:** no flaky sleeps, no mega-tests, no "seems right".
